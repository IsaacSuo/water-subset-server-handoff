# 交互式物理世界模型数据集执行计划

状态：v0.1 规划基线

工作分支：`dataset/interaction-world-model-v0.1`

流体封存基线：`fluid-v13-closure-20260914`

## 目标

构建动作条件的多物理交互数据集，研究不同物体受到作用后如何运动、接触和变形。
第一版以刚体和体积软体为主体，提供可复现动作、成对反事实、物理真值、多视角
观测和分布外评测。布料、绳索和流体在核心协议稳定后扩展。

数据集的基本单位是事件 episode：

```text
环境 + 装置 + 物体几何 + 物理属性 + 外部作用 + 相机
                         ↓
                    episode
```

环境、事件、几何、物理属性和视觉材质必须独立引用。已有 14 个环境用于视觉域和
环境碰撞泛化，不再各自绑定一种事件。

## v0.1 范围

- 10 个刚体或体积软体核心事件。
- 6 种标准诊断几何，并复用一部分现有复杂 STL。
- 每个事件至少 6 组严格单变量对照。
- 目标规模约 360 条物理 episode。
- 全量输出低成本 RGB-D、分割、法线和运动数据。
- 仅为 5%–10% 的代表样本生成 Blender Cycles 高质量画面。
- 同时保留正常、边界和失败结果。

第一版不包含塑性、断裂和新的流体类型。绳索必须先通过能力探针，才进入正式范围。

## 标准几何

首批标准几何为球、圆柱、圆角立方体、胶囊或长杆、L 形物体和环形或凹形物体。
它们负责定量诊断；现有动物、植物和日常物体 STL 负责复杂几何泛化。

物理属性与视觉材质分开配置。受控子集必须包含相同物理属性的多种外观，以及相同
外观的不同物理属性，防止模型只根据透明、金属或颜色猜测动力学。

## Episode 合同

每条 episode 由以下字段唯一确定：

```text
schema_version
episode_id
event_id
object_ids
physics_profile_ids
appearance_profile_ids
environment_id
fixture_parameters
action_parameters
camera_set_id
seed
source_commit
```

标准输出至少包含：

```text
episode.json
action.json
observations/
state/
contacts.jsonl
metrics.json
validation.json
```

状态真值包括刚体位姿、线速度和角速度；软体表面和 simulation tet；接触对象、
接触位置、法线和冲量；物体级能量；压缩率、恢复率和非刚性形变量。所有数据使用
真实秒数和显式时间戳，动作不能只依赖渲染帧号表达。

## 停止规则

- 没有动作定义、物理真值和评价指标的场景不进入正式数据集。
- 物理缓存未通过审核时不启动高质量渲染。
- 背景数量不能代替事件数量；随机参数不能代替单变量反事实。
- 单个视觉问题只做有界诊断，达到统一最低标准后停止。
- v0.1 不新增流体类型，不实现塑性和断裂。
- 绳索能力探针未通过时不承诺绳索数据。
- 两个纵向原型通过前不启动大规模批量生成。
