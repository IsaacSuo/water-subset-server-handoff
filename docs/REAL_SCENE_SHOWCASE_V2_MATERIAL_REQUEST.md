2. **绳索绕杆滑移，G01**：原 pipe 的低 X 管，中心截面 (-1.58488824,-1.7,2.85450650)，原直径约 49.21 mm。半径 3 mm 的自由绳，初始中心线跨过原杆上侧，两端约 0.35/0.60 m 的不等余长；零初速度、无主动控制，观察重力导致的绕接、滑移或脱离。不得用固定圆柱代理代替 pipe。保留该物体全部原三角面及能触及的邻接结构，初态须查三维净空。目标记录 3 s、至少 60 Hz；先原生缓存和关键帧，再决定是否延长。
