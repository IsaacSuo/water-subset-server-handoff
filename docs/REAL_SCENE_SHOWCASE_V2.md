2026-09-17。用户最新要求覆盖旧版“优先复用片段”的安排。本轮重新生成物理过程，并在 Christophe Seux 原 Classroom 中回放完整材质。旧总览和旧缓存保持原样。本轮不增加 split、训练、全面数值研究或同场多后端耦合，不包含黏弹性、流体、损伤和分离。

根目录：`output/world_model_dataset/v0_2/real_scene_showcase_v2/`。

## 实现

- `real_scene_batch.py` 接受镜头和适用资产列表，按显式尺寸、姿态与原支承网格射线放置。保留 SDF256，不退回单凸包。三个环境组全部保持原位并参与刚体碰撞。
- `scene_cache_replay.py` 为通用原场景入口。刚体读取位姿；布料更新原生三角面；绳索显示原生碰撞胶囊；MPM 使用明确标注的派生外观表面。旧 `blend_scene_replay.py` 保留其历史用途。
- glTF 外观保留原层级的所有网格、材质和 UV。先撤销 Blender glTF 导入的 Y-up→Z-up 基变换，再做源归一化、COM、尺寸变换，最后施加物理位姿；各资产渲染前执行双向最近顶点误差检查。
- MPM 显示以 24 邻近初始材料点的局部仿射 MLS 更新扫描表面，保留原 UV／贴图；静止重建误差有检查。该表面不是 MPM 原生拓扑，不作为新的物理真值。
- `real_scene_material_request.py` 为闭合真实资产列表生成材料接口输入；原几何、尺寸、坐标和初始离地高度都显式记录，不硬编码逐件资产逻辑。
- 原 blend 与实例变换不改动，不保存源文件；相机按遮挡修正，原材质和原灯光保留。用户明确暂不投入灯光调整。

## 预览与修正

先制作 640×400、8 samples 的整批完整外观动态预览，再集中渲染清晰版本。原首次窗外方向机位被百叶窗遮挡，已只改相机；椅架镜头改为低机位，布料改为能看到桌沿下垂的一侧。绳索靠近天花，正交相机的上侧射线穿过梁；用原几何可见性检查选取室内透视机位，不删遮挡物。

滚滑第一版运动较短，保留为诊断；第二版给洋葱合法初始角速度，分别声明两物体初态，不包装为严格形状对照。最终没有增加多个相似推动或柜沿跌落镜头。

材料线 `classroom_rope_v1` 原竖管候选不采用：缓存中心线距未纳入碰撞的原墙面采样最小仅 0.433 mm，而绳半径 5 mm。改用 G01 新物理缓存；并非只替换渲染背景。G01 材料诊断栅格器因相机近裁剪失败发生在原生仿真、episode 封装之后，主线直接读取成功缓存，未重跑物理。

## 检查与解释边界

- 直接审有限状态、初态、环境恒定位姿、原生接触对象对、关键画面、原场景与状态哈希；见 `cache_review.json` 和各 `replay.json`。
- 刚体物体—桌面／椅架及多体间接触来自原生报告。多体样本最大相关原生负 separation 约 2.04 mm，保留原记录；没有额外参数扫描。
- 布料扫掠区域可能重叠包围盒的遗漏 woodBase，经实际三角网格查询最小采样距离约 0.365 m；桌架已经包含。绳索实际扫掠保持在所选原对象区域，采样中心线／胶囊半径检查未检出穿入，最大连接端点间隙约 1.125 mm。
- MPM 577 个每步状态；Jp 末态均值约 0.874、范围约 0.099–1.031，诊断变形梯度最小行列式约 0.118，未出现负值。支承和重力始终存在，不能把末态几何直接称作完全卸载永久应变。
- 柔性接触力与冲量缺失处保持 unavailable。布料仍使用材料线局部 surface 读取适配，不声称共享核心任意软体接口已完成。
- 所有短片来自对应缓存，没有手工补运动、放大形变、加粗绳索或隐藏物理参与体。显示为两倍慢放，不插值制造物理帧。

## 本地复现入口

```bash
# 新 episode 必须使用新输出/镜头 ID，旧缓存不会自动重跑
python -m world_model_dataset.real_scene_batch \
  --spec configs/dataset/v0_2/real_scene_showcase_v2.json --output output/new_real_scene_batch

# 带缓存哈希、相机和材质对齐记录的原场景回放
blender -b --python world_model_dataset/scene_cache_replay.py -- \
  --plan output/world_model_dataset/v0_2/real_scene_showcase_v2/final_render_plan.json

python -m world_model_dataset.real_scene_delivery \
  --catalog output/world_model_dataset/v0_2/real_scene_showcase_v2/delivery_catalog.json \
  --output output/new_real_scene_delivery
```

使用现有 WSL 材料 Python 环境、Windows Isaac Sim 刚体后端、Blender 5.0.1 和 ffmpeg。输出为局部展示交付，不是数据集完整发布或材料标定结果。
