## 实现

- `real_scene_batch.py` 接受镜头和适用资产列表，按显式尺寸、姿态与原支承网格射线放置。保留 SDF256，不退回单凸包。三个环境组全部保持原位并参与刚体碰撞。
- `scene_cache_replay.py` 为通用原场景入口。刚体读取位姿；布料更新原生三角面；绳索显示原生碰撞胶囊；MPM 使用明确标注的派生外观表面。旧 `blend_scene_replay.py` 保留其历史用途。
- `scene_cache_comparison.py` 按显式面板列表合成同屏对比：必须具有相同物理时间、相机、尺寸、采样率和原场景哈希，并检查两组物理缓存哈希。只竖向拼接原始渲染像素并加标签；保留两条独立 episode 的来源，合成结果不是新的仿真。
- glTF 外观保留原层级的所有网格、材质和 UV。先撤销 Blender glTF 导入的 Y-up→Z-up 基变换，再做源归一化、COM、尺寸变换，最后施加物理位姿；各资产渲染前执行双向最近顶点误差检查。
- MPM 显示以 24 邻近初始材料点的局部仿射 MLS 更新扫描表面，保留原 UV／贴图；静止重建误差有检查。该表面不是 MPM 原生拓扑，不作为新的物理真值。
- `real_scene_material_request.py` 为闭合真实资产列表生成材料接口输入；原几何、尺寸、坐标和初始离地高度都显式记录，不硬编码逐件资产逻辑。
- 原 blend 与实例变换不改动，不保存源文件；相机按遮挡修正，原材质和原灯光保留。用户明确暂不投入灯光调整。

## 预览与修正

用户已接受 640×400、8 samples 的完整外观预览，明确不需要清晰版。已停止清晰版任务，`final_render/` 的不完整内容保留但不交付。替换多体和布料两段，其余四个视频按哈希核对后原样复用。原首次窗外方向机位被百叶窗遮挡，已只改相机；椅架镜头改为低机位，布料改为能看到桌沿下垂的一侧。绳索靠近天花，正交相机的上侧射线穿过梁；用原几何可见性检查选取室内透视机位，不删遮挡物。

多体原版的边缘洋葱在 3 s 时质心仍位于桌沿内约 26.85 mm，虽然外观悬出约 21.58 mm，但仍有支承且轻微滚动。用户要求让它掉落：先只移动该洋葱 5 cm 的版本反而滚回桌内；最终 `desk_rearrangement_edge_v3` 将四物体初始排列整体沿 +Y 平移 7 cm，保留相对位置、质量、摩擦、零初速度和原场景几何，记录 4.5 s。轨迹中洋葱最终从 +X 桌沿滚出，约 1.521 s 与原地面产生非零接触冲量，末态质心高约 35.4 mm、速度约 0.048 m/s。不能描述为全部静止。室内透视机位覆盖初始分层、碰撞、下降和落地；按物理时间 30 Hz 读取，2 倍慢放。

新布料为 64×44 单元、2925 节点，1200 Hz 求解、32 次位置迭代，接触更新、接触子迭代和阻尼同时调整，原生保存 60 Hz、3 s。主线读取全部 181 个缓存状态并以 30 fps／2 倍慢放交付；不做位移过滤、时间插值或显示细分。同一 1.5–2 s 窗口的速度 RMS 从 0.2237 降至 0.03928 m/s，帧间节点位移 P95 从 4.309 降至 0.430 mm。仅说明该配置的运动质量改善，不把全部位移当数值抖动，也不声称仅增加分辨率造成改善或已经证明收敛。

按用户要求，椅架片段进一步改为上下同步姿态对比 `chair_orientation_comparison_v1`，替换单一受阻镜头。原 24 cm 水壶平放厚约 14.6 cm，略超原通道最低约 14.5 cm 净空，因此两组统一使用 22.5 cm 规格：平放厚 13.69 cm，立放高 17.27 cm。两组初始 XY 都为 (-0.3, -1.0) m，初速度均为 (2.2, 0, 0) m/s，质量均为 0.55 kg，摩擦和原场景完全相同；只有姿态及由原地面支承决定的 COM 高度不同。重新生成 `chair_pair_flat_v1`、`chair_pair_upright_v1`，各 2 s，未改变原场景结构。

原限制段为 x≈−0.15…0.4 m，以整个水壶最小 x>0.6 m 作为完全进入出口的保守判据。平放在 0.5833 s 满足，未记录与椅架所属环境组的非零冲量接触，最终停在 x≈1.186 m；立放在 0.0625 s 接触原杆，接触点 z≈0.1576 m，最终仍处于入口前且保持直立。相同机位分别渲染 640×200，30 Hz／61 帧，再上下合为 640×400，以 2 倍慢放展示。其余五段编码视频按哈希原样复用。

滚滑第一版运动较短，保留为诊断；第二版给洋葱合法初始角速度，分别声明两物体初态，不包装为严格形状对照。最终没有增加多个相似推动或柜沿跌落镜头。

材料线 `classroom_rope_v1` 原竖管候选不采用：缓存中心线距未纳入碰撞的原墙面采样最小仅 0.433 mm，而绳半径 5 mm。改用 G01 新物理缓存；并非只替换渲染背景。G01 材料诊断栅格器因相机近裁剪失败发生在原生仿真、episode 封装之后，主线直接读取成功缓存，未重跑物理。

## 检查与解释边界

- 直接审有限状态、初态、环境恒定位姿、原生接触对象对、关键画面、原场景与状态哈希；见 `cache_review.json` 和各 `replay.json`。
- 刚体物体—桌面／椅架及多体间接触来自原生报告。旧多体样本最大相关原生负 separation 约 2.04 mm；新的掉落版本在首次地面撞击时出现约 13.92 mm 瞬时负 separation（240 Hz 离散接触），随后被求解器纠正，保留完整原记录，不声称无穿透或精确冲击力。没有额外参数扫描。
- 布料扫掠区域可能重叠包围盒的遗漏 woodBase，经实际三角网格查询最小采样距离约 0.365 m；桌架已经包含。绳索实际扫掠保持在所选原对象区域，采样中心线／胶囊半径检查未检出穿入，最大连接端点间隙约 1.125 mm。
- MPM 577 个每步状态；Jp 末态均值约 0.874、范围约 0.099–1.031，诊断变形梯度最小行列式约 0.118，未出现负值。支承和重力始终存在，不能把末态几何直接称作完全卸载永久应变。
- 柔性接触力与冲量缺失处保持 unavailable。布料仍使用材料线局部 surface 读取适配，不声称共享核心任意软体接口已完成。
- 所有短片来自对应缓存，没有手工补运动、放大形变、加粗绳索或隐藏物理参与体。显示为两倍慢放，不插值制造物理帧。
- `replacement_cache_review.json` 核对新刚体有限状态、原环境不动、初态仅平移、无 t0 后直接写位姿，以及布料全部 181 个几何状态的节点数／有限值／哈希。新布料原始缓存 SHA256 为 `4f796f1d42077df15e3297639da6920c7167042de3ed98fc4e5cd4be37ee87f8`。
- `chair_pair_review.json` 核对两组网格、环境、质量、材料、初始 XY／速度相同，有限状态和环境静止，且 t0 后无直接位姿写入。平放与立放的原生最大负 separation 分别约 0.73、0.79 mm。同步合成的 3 项测试覆盖源哈希变化、时间／相机不匹配及像素和双来源保留。

## 本地复现入口

```bash
# 新 episode 必须使用新输出/镜头 ID，旧缓存不会自动重跑
python -m world_model_dataset.real_scene_batch \
  --spec configs/dataset/v0_2/real_scene_showcase_v2.json --output output/new_real_scene_batch

# 带缓存哈希、相机和材质对齐记录的原场景回放
blender -b --python world_model_dataset/scene_cache_replay.py -- \
  --plan configs/dataset/v0_2/real_scene_showcase_v2_replay.json

# 姿态对比需要先生成两组回放，再同步合成；输出必须使用新目录
python -m world_model_dataset.scene_cache_comparison \
  --plan configs/dataset/v0_2/real_scene_chair_pair_composition.json \
  --output output/new_chair_comparison

python -m world_model_dataset.real_scene_delivery \
  --catalog configs/dataset/v0_2/real_scene_showcase_v2_delivery.json \
  --output output/new_real_scene_delivery
```

使用现有 WSL 材料 Python 环境、Windows Isaac Sim 刚体后端、Blender 5.0.1 和 ffmpeg。输出为局部展示交付，不是数据集完整发布或材料标定结果。
